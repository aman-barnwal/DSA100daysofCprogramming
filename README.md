### Problem 2: Best Time to Buy and Sell Stock (LeetCode)

**Description**  
You are given an array `prices` where `prices[i]` is the price of a stock on the `iᵗʰ` day.

**Concepts Used**
- Arrays  
- Single-pass traversal  
- Greedy approach  

**Time Complexity**
